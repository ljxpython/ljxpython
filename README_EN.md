### 🧪 QA Engineering Roots

Before focusing on AI, I spent years in QA engineering — building automation frameworks, load testing systems, and full-stack test platforms from scratch. Two habits stuck: caring about system stability, and thinking about failure modes before writing code. That said, the actual build order is still features first: get the functionality working, then once it's stable, go back and add performance hardening, security, and observability. The testing projects are still maintained; feel free to use them.
