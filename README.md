做 AI 工程之前，我在测试开发领域做了几年：自动化框架、压测体系、测试平台前后端全栈，都自己搭过。这段经历给我留下了两个习惯：对系统稳定性比较执着，以及写代码先想"这东西怎么坏"。不过做工程的顺序还是先把功能跑通，功能稳定之后再加固性能、安全和可观测，不会一上来就先搭监控。测试相关项目持续维护，欢迎参考。
